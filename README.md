# Server Health Monitoring and Alert System Using DevOps

## 1. Introduction

This project monitors server health and identifies
resource utilization problems using DevOps tools.

## 2. Objectives

1. Monitor CPU usage.
2. Monitor RAM usage.
3. Monitor disk usage.
4. Generate alerts when usage exceeds 80%.
5. Collect metrics using Prometheus.
6. Manage alerts using Alertmanager.
7. Automate deployment using Jenkins.
8. Containerize applications using Docker.

## 3. Technologies Used

- Python
- Prometheus
- Alertmanager
- Node Exporter
- Docker
- Docker Compose
- Jenkins
- Git and GitHub

## 4. Project Execution

1. Install required software.
2. Configure Prometheus.
3. Configure Alertmanager.
4. Create Python monitoring application.
5. Build Docker image.
6. Start containers using Docker Compose.
7. Access Prometheus dashboard.
8. Configure Jenkins pipeline.

## 5. Dashboard URLs

Prometheus: http://localhost:9090

Alertmanager: http://localhost:9093

Node Exporter: http://localhost:9100/metrics

## 6. Conclusion

This project provides automated server health
monitoring using DevOps technologies. It collects
server metrics, detects high resource utilization
and generates alerts to improve system reliability.
